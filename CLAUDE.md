# Claude Code session preferences (this repo)

## Pull requests: create ready for review, not draft

When opening a pull request in this repo, create it ready for review
(`draft: false`), not as a draft. The user wants PRs visible in a
"ready for merge" status as soon as they're pushed, not sitting in
draft state.

This does not change any other PR governance in this repo (protected-path
review requirements, self-merge prohibition, reviewer-lifecycle gate, etc.)
— it only changes the draft/ready flag at creation time.
