# Tutorial: Build Content Inventory

## Steps

1. Define story tags from Eig book
2. Create D1 records (tag, title, text)
3. Assign story_type and allowed_sections
4. Search for supporting media
5. Deduplicate against existing stories
6. Upload approved media to B2
7. Link media in D1

Result: one complete story block ready for rendering
